# 图片选择题设计

## 目标与已确认方向

在现有复习流程中自动混入两种单选题：德语单词选图片（word-image）、图片选德语单词（image-word）。用户已确认沿用现有随机题型系统和交互布局，不增加练习模式设置。

2026-10-29 补充要求：**图片选单词时，名词选项不显示 der / die / das，只显示名词本身**，避免借助图片冠词颜色排除答案。例如显示 Apfel、Hund、Stuhl、Auto。保留德语大小写、变音符号和短语原文。

## 方案选择

- 已选择：向现有 chooseQuizType 扩展两个题型，复用词条、图片路径、答题判定和记忆调度。实现范围小，能自然跳过不适用题型。
- 未选择：按整场配额安排题型。可保证比例，但增加短场次、缺图和错题重排的复杂性。
- 未选择：逐词维护人工干扰项。可精确控制混淆度，但需要额外维护大词库。

本次只设计和复用现有图片，不生成、修改或重新审核图片素材，不修改 TXT 格式、词库进度键或记忆算法。

## 题型概率与适用条件

从每个词条实际可用的题型中等概率抽取：有释义才有释义题，名词才有冠词题，填空题始终保留；图片题要求目标有图片，且当前选定词库中可以组成四个有效、不同的选项。

因此，有释义、有图片且候选项充足的名词共五种题型，各约 20%，两种图片题合计约 40%。非名词没有冠词题，可用四种题型各约 25%。这沿用现有适用条件，不制造无意义的冠词题，也不强制保证每场比例。

新词先展示现有学习卡；进入复习阶段后才参与图片题随机选择。错题沿用当前流程，在后续队列中以原题型重新出现。

## 交互与布局

### 德语单词选图片

提示为“选择对应的图片 / Choose the matching picture”。上方显示完整德语词条，名词包含冠词，允许点击发音。下方为 2×2 图片按钮，使用现有图片，等尺寸、完整呈现主要内容；答题前不显示单词或释义标签。

### 图片选德语单词

提示为“选择对应的德语单词 / Choose the matching German word”。上方显示一张图片，下方为四个德语文字按钮，通常为 2×2；长短语在窄屏可改为单列，不截断内容。

**答题前所有名词选项隐藏冠词，不以文字颜色、边框颜色、背景色或性别标签标记词性。** 整张题卡以及背后的下一张预览卡均使用中性色。不得在隐藏标签、可访问名称、工具提示或预览中额外暴露目标词、冠词或释义；也不在答题前自动朗读目标词或提供其发音按钮。

词选图同样使用中性题卡，保留原图片的冠词配色。桌面和手机均沿用现有单张复习卡；设计预览中的两张卡只是并排说明两种题型。

### 答案反馈

单击或键盘激活即提交，一题只记一次结果。用边框和正确/错误文字标记所选项；答错时同时标记正确项，不能只靠颜色反馈。

答对沿用现有约一秒后进入下一题；图片选词在反馈中显示完整词条，如“回答正确：der Apfel”。答错停留，反馈显示带冠词的正确词条，并保留“复习词卡 / 继续”。查看学习卡后返回原题，不重新计分、不重新打乱选项。

## 干扰项与题目稳定性

候选项仅来自当前 WORDS 范围，即当前选定词库或自定义单元的全部词条，不局限于本次抽到的 10/20 个词。

- 每题严格四选一：一个目标词条和三个随机干扰词条，使用词条身份判定答案。
- 两种题型都从有图片的候选词条中取项，复用同一候选规则；不足四项时使用原有题型，不出现单选项或空白图片。
- 排除相同图片路径、相同完整德语词条及相同非空释义的干扰项；图片选词额外按去掉冠词后的可见文本去重，不能同时出现两个相同按钮文字。
- 候选去重按当前显示规则处理大小写及空白；德语变音符号保留，不把不同德语词误合并。
- 不引入语义模型或新依赖。自动规则不能识别所有近义词和抽象画面歧义，这是初版限制；遇到具体问题再记录并排除相应配对。
- 选项在题目首次准备时生成并缓存在 session item 上。预览、正式展示、切换界面语言及错题回看均使用同一份顺序。错题重新排入队列后作为新一题可重新取项。

## 图片加载与可访问性

图片题所需图片加载成功后才允许提交。某图加载失败则将该路径记为本次会话不可用，当前题无惩罚地切换到可用的原有文字题；不能删除图片后继续让用户在残缺选项中作答。异步图片回调须核对当前题，避免离开题目后修改下一题。

图片按钮支持 Tab、Enter 和 Space，有可见焦点；图片选项可访问名称使用“图片选项 1”等中性编号，不能把德语答案直接放入名称。保留可访问的文字练习路径：图片题提供低强调的“切换文字题 / Use a text question”操作，无惩罚地将当前词换成原有题型。视觉识别本身无法用会直接泄题的替代文本等价考查。

中英文切换只改变提示、反馈与按钮文案，德语选项不变；切换不重新抽题、不更改已提交状态。反馈通过现有 status 区域宣布。

## 实现边界

沿用现有无框架 JavaScript 和 CSS，不增加依赖或通用测验框架。主要改动点为 app.js 的题型选择、选项生成、当前题渲染、下一题预览、正确答案反馈和图片失败处理；styles.css 增加图片按钮布局；README 补充题型说明。

继续复用 imagePath、imageUrl、displayWord(word, false)、checkQuiz 和现有复习记录。图片测验不能直接使用会把词条名称写入 alt 的学习卡 imageMarkup。两种题型共享词条记忆进度，不增加按题型独立的熟练度记录。

## 验收要点

1. 符合五种题型条件的词条可抽到所有五种；无图、非名词、无释义和候选不足分别只排除不适用题型。
2. 四个选项各不相同、只有一个正确项；同图、重复词条、去冠词后重名及相同释义不会制造多个答案。
3. 图片选词答题前所有名词选项均无冠词，卡片及选项不按性别着色；答题后完整词条可正确显示冠词。
4. 答对、答错、错题再出现、回看返回和切换语言均正确计分并保留应保留的题目状态。
5. 图片失败或切换文字题不会记错、消耗当前词条的复习机会或触发旧题异步回调污染新题。
6. 在桌面及约 360px 手机宽度检查两种题型、长词、键盘焦点与中英文反馈，无横向溢出；原有三种题型及复习进度无回归。
